Install

Open Terminal (press ⌘ Space, type Terminal, press Return) and paste each command. About 10 minutes, once. Step 4 downloads ozen for you, so you don't need the button above.

  1. Apple's developer tools. Click Install in the window that pops up. Already installed? Move on.
    xcode-select --install
  2. Homebrew, the standard way to add tools to a Mac. It asks for your Mac password (typing shows nothing; that's normal). When it finishes it prints Next steps: run those too. Skip if you have Homebrew.
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  3. The tools ozen runs with.
    brew install uv ffmpeg
  4. Download ozen and add it to your Applications. It unpacks into a folder named ozen in your home folder, with a private voices folder for the voices it learns.
    curl -fL https://pub-c924dc0ced674b94a6c670ac43ee914b.r2.dev/ozen-latest-macos-arm64.tar.gz | tar -xz -C ~ && git init -q ~/ozen/voices && ~/ozen/target/release/ozen app
  5. Open ozen. Press ⌘ Space, type Ozen, press Return. An ear appears in the menu bar; that's the app.

Updating: run step 4 again. It never interrupts a recording, and your voices and permissions stay.

Next: allow ozen to listen, then your first meeting.
